# 开发路线图

## v0.1 项目骨架（当前）

- [x] Vite + Vue 3 + TS 工程，hash 路由，相对路径部署
- [x] iPad 横屏自适应布局（`--key` 方案）、竖屏提示
- [x] 屏幕键盘：指法着色、目标键高亮、Shift 提示、按下/按错反馈、触屏点击输入
- [x] 手指示意图：高亮手指 + 文字说明，自动/显示/隐藏策略
- [x] 通用打字会话：阻塞/自由纠错、计时、速度、正确率、星级
- [x] 基础键盘 22 课
- [x] 英文单词 8 个主题（中英对照）
- [x] 英文文章（分级 + 译文）
- [x] 中文文章：拼音打字、中文输入法对照
- [x] 自定义练习：英文 / 中文转拼音 / 中文输入，拼音预览
- [x] 游戏：气球大作战（4 种模式）
- [x] 设置、练习记录

## v0.2 内容与体验

- [ ] 扩充内容：单词按年级（人教版小学英语 3~6 年级）分册；更多古诗与课文
- [ ] 单词练习“听写模式”：隐藏英文，只看中文 / 听发音（Web Speech API）
- [ ] 英文单词发音（`speechSynthesis`），打完一个词自动朗读
- [ ] 拼音练习“声调提示”开关（显示带声调拼音）
- [ ] 课程进度与解锁：每课得到星星，记录最佳成绩
- [ ] 错误键统计：练习结束后展示最容易打错的键，生成针对性练习
- [ ] 结果页“慢动作回放”：重放打字过程
- [ ] 每日目标与连续打卡

## v0.3 更多游戏

- [ ] 打地鼠：地鼠举着字母冒出，适合基准键入门
- [ ] 打字赛车：与电脑/历史最好成绩赛跑，文章速度练习
- [ ] 太空保卫战：陨石带单词/拼音落下，打出即可击落
- [ ] 游戏难度选择与排行榜（本地）

## v0.4 工程化

- [ ] PWA：Service Worker 离线缓存、应用图标、启动画面
- [ ] 单元测试（Vitest）：typing-session、pinyin 对齐、keyboard-layout
- [ ] E2E 测试（Playwright，iPad 视口）
- [ ] 多用户档案（同一台 iPad 多个孩子）
- [ ] 记录导出 / 导入（JSON）
- [ ] 可选：家长端查看练习报告（需后端，单独评估）
