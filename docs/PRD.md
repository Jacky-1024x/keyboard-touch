# 产品需求与功能设计

## 1. 产品定位

- **用户**：6~12 岁小学生（家长/老师辅助），零基础到能盲打。
- **设备**：以 iPad 横屏 + 外接键盘为主，兼顾电脑浏览器；无外接键盘时屏幕键盘可点击作为兜底。
- **形态**：纯 H5，无需安装、无需登录、无后端，可添加到 iPad 主屏幕全屏运行。
- **目标**：建立正确指法 → 熟悉英文/拼音输入 → 提升速度；通过游戏和星级奖励保持兴趣。

## 2. 通用交互规则

| 规则 | 说明 |
| --- | --- |
| 开始计时 | 敲下第一个键时开始计时，不需要点“开始”按钮 |
| 纠错模式 | **阻塞模式**（默认）：打错不前进，按错的键闪红，必须打对才继续，打错后改对的字符显示为橙色。**自由模式**（仅文章类，可在设置中开启）：打错也前进，可退格修改 |
| 速度单位 | 英文：词/分（WPM，每 5 个正确字符算 1 词）；拼音/中文：字/分 |
| 正确率 | (总击键 − 错误击键) / 总击键 |
| 星级 | 3 星：正确率 ≥ 95% 且速度达标（英文 ≥ 15 词/分，中文 ≥ 30 字/分）；2 星：正确率 ≥ 85%；其余 1 星 |
| 快捷键 | Enter：结果页“再来一次”；Esc：返回上一级 |
| 结果记录 | 每次完成写入本地记录（最多 200 条），首页展示最近 5 条 |

### 屏幕键盘与手指提示

- 屏幕键盘为标准美式 QWERTY 布局，按指法分区着色（可在设置中关闭着色）。
- 下一个要按的键以白框呼吸灯高亮；需要 Shift 时同时高亮**另一只手**的 Shift。
- 实体键盘按下时屏幕键盘同步下沉；按错的键闪红。
- 手指示意图：高亮需要用到的手指，并显示文字说明（如“用 左手食指”）；指尖标注基准键 ASDF / JKL;。
- 显示策略（设置 → 手指提示）：
  - **自动**（默认）：基础键盘、英文单词显示；文章、自定义练习隐藏。
  - 总是显示 / 总是隐藏。
  - 练习页右上角可临时开关手指和键盘。

## 3. 功能模块

### 3.1 基础键盘练习

- 分 4 关，共 22 课：
  1. 基准键：F J → D K → S L → A ; → 基准键综合 → G H
  2. 上排键：E I → R U → T Y → W O → Q P → 上排综合
  3. 下排键：V M → C , → X . → Z / → B N → 下排综合
  4. 进阶：全部字母、数字键、大写字母（Shift）、常用标点
- 每课随机生成 12~20 组 2~5 个字符的练习串，**新键出现概率 60%**，其余为复习键；“再来一次”重新生成。
- 默认显示手指，大字号显示。

### 3.2 英文单词练习（中英对照）

- 主题词库：动物、水果、颜色、数字、家庭、学校、身体、食物（每个 10~12 词）。
- 每个单词上方显示中文释义，当前单词的释义高亮为蓝色。
- 每次进入打乱顺序。
- 默认显示手指。

### 3.3 英文文章练习

- 竖列目录选择：标题 + 作者/出处一行，按「伊索寓言 / 童谣 / 短文」分组。
- 经典寓言、童谣与简易短文，适合小学生。
- 练习页右上角「目录」可切换任意英文篇目。
- 保留原文标点和大小写；可开关“译文”。
- 默认隐藏手指。

### 3.4 中文文章练习

入口为四大分类（避免卡片列表过长）：**唐诗、宋诗宋词、古文、小学课文**。选择分类后自动进入该分类第一篇；练习页「目录」以「标题 + 作者」竖列切换同分类篇目。

两种练法，在分类页右上角切换：

1. **拼音打字**：汉字自动注音；`ü` 用 `v`；标点只展示不输入。
2. **中文输入（输入法）**：系统输入法直接打汉字，与原文逐字对照。

内容覆盖必背唐诗、常见宋诗宋词、三字经/百家姓/千字文/弟子规分章，以及小学课文与小古文。

### 3.5 自定义练习

- 输入或粘贴任意文本（≤ 2000 字），可填写标题。
- 自动识别：
  - 不含汉字 → **英文练习**
  - 含汉字 → 可选 **拼音练习**（自动转拼音，含实时拼音预览）或 **中文输入练习**
- 中文文本里夹杂的英文单词/数字会作为普通字母输入。
- 自定义内容保存在 sessionStorage，刷新练习页不丢失。

### 3.6 打字游戏

以英文、拼音打字为基础，增加趣味性。

**已实现：气球大作战**

- 气球从底部飘上来，打出气球上的内容即可打爆；气球飞出顶部扣 1 颗心，共 5 颗心。
- 输入首字母自动“锁定”最高的匹配气球（白框），已输入部分显示绿色；退格键取消锁定。
- 连击加分（最多 +100%），每打爆 8 个升一关，气球更快、更多。
- 四种模式：
  | 模式 | 气球显示 | 需要输入 |
  | --- | --- | --- |
  | 字母气球 | 大写字母 | 对应字母 |
  | 单词气球 | 英文 + 中文 | 英文单词 |
  | 看中文打英文 | 中文 + 首字母提示 | 英文单词 |
  | 拼音气球 | 汉字（第 1 关附拼音提示） | 无声调拼音 |
- 游戏结束显示得分、速度、正确率并记录。

**规划中**：打地鼠（字母）、打字赛车（文章速度）、太空保卫战（单词/拼音），见 [ROADMAP](ROADMAP.md)。

### 3.7 设置与记录

- 昵称、按键音效、显示屏幕键盘、键盘指法着色、手指提示策略、文章自由纠错模式。
- 练习记录列表（时间、类型、内容、速度、正确率、游戏得分），可清空。

## 4. 非功能需求

- **适配**：iPad 横屏（1024×768 ~ 1366×1024）一屏内完整显示文本区 + 键盘 + 手指，不出现页面级滚动；详见 [UI-LAYOUT](UI-LAYOUT.md)。
- **性能**：首屏 JS ≈ 40KB gzip；拼音词库（≈ 140KB gzip）仅在进入拼音相关页面时按需加载。
- **离线**：当前需联网加载页面；后续计划加入 PWA 离线缓存。
- **隐私**：无账号、无上报，所有数据只存在本机浏览器。
