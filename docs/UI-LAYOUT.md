# iPad 横屏 UI 适配方案

## 1. 目标设备

| 设备 | 横屏 CSS 尺寸 |
| --- | --- |
| iPad（第 9 代及以前） / iPad mini | 1024 × 768 / 1133 × 744 |
| iPad Air / iPad（第 10 代） | 1180 × 820 |
| iPad Pro 11" | 1194 × 834 |
| iPad Pro 12.9" | 1366 × 1024 |
| 笔记本浏览器 | 1280 × 720 起 |

Safari 浏览器模式下地址栏和标签栏会占用约 70px，添加到主屏幕后为全屏。布局使用 `100dvh` 适配两种情况。

## 2. 练习页布局

```
┌──────────────────────────────────────────────┐
│ ‹  标题  副标题               🖐 ⌨️ 译文 🔄 │  页头 64px
│ 00:12 用时   18 词/分   96% 正确率  ▓▓▓░░░ │  统计栏 44px
│ ┌──────────────────────────────────────────┐ │
│ │       猫     狗                          │ │
│ │       cat  dog  ...                      │ │  文本区：弹性高度，最小 200px
│ └──────────────────────────────────────────┘ │  内容过多时内部滚动，当前字符居中
│   ┌──────────────────────────────────────┐   │
│   │            屏幕键盘 5 行               │   │  5.6u
│   └──────────────────────────────────────┘   │
│        ✋ 左手           右手 ✋             │  手指 2u（可隐藏）
└──────────────────────────────────────────────┘
```

整个页面 `height: 100dvh; overflow: hidden`，**不出现页面级滚动**，只有文本区内部滚动。

## 3. 键盘尺寸：`--key`

所有键盘和手指尺寸都基于 CSS 变量 `--key`（一个字母键的边长），在 `styles/global.css` 中计算：

```css
--key: min(
  /* 宽度约束：一行 15u 键 + 键间距 + 内边距 ≈ 16.4u */
  calc((100vw - var(--page-pad) * 2 - 8px) / 16.4),
  /* 高度约束：扣除页头、统计栏、文本区最小高度后，键盘 + 手指共 --kb-rows-u 行 */
  calc((100dvh - var(--header-h) - var(--stats-h) - var(--text-min-h) - 48px) / var(--kb-rows-u)),
  /* 上限，避免大屏上键过大 */
  72px
);
```

| 场景 | `--kb-rows-u` | `--text-min-h` |
| --- | --- | --- |
| 显示手指 | 7.6（键盘 5.6 + 手指 2） | 200px |
| 隐藏手指（`.no-hands`） | 5.8 | 280px（给文章更多空间） |
| 矮屏（高度 ≤ 700px） | 同上 | 150px，页头 52px，边距 16px |

> CSS 自定义属性在声明处计算，所以 `--key` 需要在练习页根元素 `.kb-scope` 上重新声明，才能读取到该元素上被 `.no-hands` 覆盖的 `--kb-rows-u`。

实测结果（显示手指 / 隐藏手指时键盘的 `--key`）：

| 视口 | 显示手指 | 隐藏手指 |
| --- | --- | --- |
| 1024 × 768 | ≈ 54px | ≈ 57px |
| 1180 × 820 | ≈ 61px | ≈ 66px |
| 1366 × 1024 | 72px（上限） | 72px |

## 4. 列表页

- 首页 3 列 × 2 行大卡片，一屏展示全部 6 个模块。
- 课程列表 6 列、词库 4 列、文章 3 列，页面内容区可纵向滚动。

## 5. 触控与浏览器细节

- `viewport`：`width=device-width, initial-scale=1, maximum-scale=1, user-scalable=no, viewport-fit=cover`，禁止双击缩放。
- `touch-action: manipulation` 去除点击延迟；`-webkit-tap-highlight-color: transparent` 去除点击高亮。
- `env(safe-area-inset-*)` 兼容圆角屏与主屏幕全屏模式。
- `apple-mobile-web-app-capable` 支持添加到主屏幕全屏运行。
- 竖屏（且为触屏设备、宽度 ≤ 1024）时显示“请横屏使用”遮罩；桌面窄窗口不提示。
- 屏幕键盘使用 `pointerdown` 而不是 `click`，响应更快，并 `preventDefault` 防止唤起系统软键盘。
